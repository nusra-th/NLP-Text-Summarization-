# 📝 NLP Text Summarization Web Application

A Natural Language Processing (NLP) based web application that automatically generates concise summaries from long text articles using a pre-trained Transformer model.

---

## 📌 Project Overview

This project focuses on **automatic text summarization**, a key task in Natural Language Processing.  
Users can input long articles or paragraphs, and the system produces a meaningful summary while preserving the core information.

The application is built using **Flask** for the web interface and **HuggingFace Transformers** for the NLP model.

---

## 🚀 Features

- Automatic text summarization
- Simple and user-friendly web interface
- Uses state-of-the-art Transformer model
- Runs on CPU (no GPU required)
- Suitable for beginners and academic projects

---

## 🧠 Model Used

- **facebook/bart-large-cnn**
  - A pre-trained Transformer model optimized for text summarization
  - Provided by HuggingFace

---

## 🛠 Technologies Used

- Python
- Flask
- HuggingFace Transformers
- PyTorch
- HTML (for frontend)
